ШАГ 1 — ПОЛУЧИТЬ API КЛЮЧ ANTHROPIC
────────────────────────────────────
1. Включи VPN
2. Зайди: console.anthropic.com
3. Sign up (через Google или email)
4. Слева → "API Keys" → "Create Key"
5. Скопируй ключ — он начинается с sk-ant-...
6. Пополни баланс на $5 (хватит надолго)
   ⚠️ Карта РФ не работает — нужна виртуальная
   (Wise, Privacy.com, или попроси знакомых)

ШАГ 2 — ЗАГРУЗИТЬ НА VERCEL
────────────────────────────────────
1. Включи VPN
2. Зайди: vercel.com → Continue with Google
3. Нажми "Add New..." → "Project"
4. Выбери "Browse" или перетащи папку albina-vercel
5. Настройки оставь по умолчанию → Deploy
6. Подожди ~1 минуту → сайт готов!

ШАГ 3 — ДОБАВИТЬ API КЛЮЧ
────────────────────────────────────
1. В Vercel → твой проект → Settings
2. Слева: "Environment Variables"
3. Добавь:
   Name:  ANTHROPIC_API_KEY
   Value: вставь свой ключ (sk-ant-...)
4. Нажми Save
5. Deployments → три точки → Redeploy

ШАГ 4 — ГОТОВО! 🎉
────────────────────────────────────
Твой сайт работает по адресу:
  имя-проекта.vercel.app

AI-инструменты на странице /demo полностью активны.
